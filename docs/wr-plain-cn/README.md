# wr-plain-cn

[← 返回 wr-skills](../../README.md) · [English](../../README.en.md#skills)

> 平实中文写作与去机器味检查。从真实小事起手、保持连贯口语长句呼吸感、按做事先后自然推进、讲透因果只举通用例子，配上四条硬封底线与三条句法检查，让文章像一个真动手踩过坑的人在当面说话。

**支持 Claude Code、Codex、Cursor、Antigravity、claude.ai，以及其他支持 Skills 的 Agent。** 用的 AI 不支持 Skill，也可以直接复制 [提示词清单](提示词清单.md)。

## 解决什么痛点

| 常见 AI 写稿毛病 | 用 wr-plain-cn 之后 |
| --- | --- |
| 开头扯宏观时代背景，正文硬套第一到第四阶段和教训模板 | 从自己真做过的一件小事起手，顺着做事先后自然展开，大白话小节标题直接说坑和办法 |
| 三五字一逗的电报碎句、一行一句装深沉，或者越改越短 | 保持 15 到 40 多字的连贯口语长句呼吸感，关键处用短句收住，保留自然口头连接词 |
| 满篇破折号、先否定再翻过来的翻案句、说教冒号与塑料假俚语 | 四条硬封底线直接清零，回到普通人日常动词和写实表达 |
| 分句里顿号连排一长串、正文爱用分号、相邻三句套同一个骨架 | 加入顿号连串、分号拆句与相邻句同构三项句法检查，并可跑本地检查脚本逐行定位 |
| 没材料就脑补心理戏，结尾强行拔高升华，同一个链接到处贴 | 零脑补心理戏，未知直写未知，同链全文只放一回，事情讲完克制收尾 |

## 核心写法

1. **真实小事起手**。从具体事情开头，讲当初想做什么、第一版看着像样、真上手后怎么接连出问题，不端架子。
2. **连贯口语长句呼吸感**。一句一口气把因果、转折、现场和举例顺下来，关键处短句收住，不写电报碎句。
3. **按做事先后自然推进**。一小节讲透一个坑和一个解决办法，不硬编阶段模板和教训句。
4. **讲透因果，只举通用例子**。每条办法写清踩什么坑、为什么会这样、具体怎么干；举例选人人都碰得到的通用场景，不塞冷门私货，不抄参考文章原话和结构。
5. **直白推荐，同链只放一回**。最值得照抄的方法直接挑明并写全细节；外部仓库或参考链接全文只放一回。
6. **零模型味底线与写实收尾**。禁破折号、翻案句、说教冒号和塑料假俚语，零脑补心理戏，落款可在 `wr.config.json` 的 `style.signature` 里自行配置。

## 三条句法检查

除了常见的词汇和标点红线，本技能额外加入了三项句法检查：

1. **顿号连串**：一个分句里用顿号连着并列三项以上（表格和刻意列全的检查清单除外），拆成逗号或拆句。
2. **分号拆句**：正文里用分号把句子接起来的，改成句号（表格除外）。
3. **相邻句同构**：相邻三句套同一个句式骨架（例如连续三句「第一道……第二道……第三道……」），打散其中一句。

顿号连串、分号、相邻句同构三项检查思路参考了 [lieflat-less-ai-tone](https://github.com/larashero3-dotcom/lieflat-less-ai-tone)。

## 可选文风检查脚本

技能目录下自带零依赖脚本 [skills/wr-plain-cn/scripts/style-check.mjs](../../skills/wr-plain-cn/scripts/style-check.mjs)（MIT 授权），可一次性扫描七类问题：破折号、翻案句、说教冒号、塑料假俚语、顿号连串、分号拆句与相邻句同构。

- **默认关闭**：不会放进 `hooks/copy-and-privacy-lint.mjs`（那个脚本只管隐私路径和密钥）。只有你在首次对齐里选择启用，并在 `wr.config.json` 里写入 `"style": { "enabled": true }` 后，项目级检查才会运行。
- **默认只报告不拦截**：启用后默认模式为 `"report"`，只列出命中的文件和行号，退出码为 `0`。需要硬拦截时把 `style.mode` 改为 `"enforce"` 或加 `--enforce`。

配置示例（放入 `wr.config.json`）：

```json
{
  "style": {
    "enabled": true,
    "mode": "report",
    "signature": ""
  }
}
```

命令行手动检查单篇草稿：

```bash
node skills/wr-plain-cn/scripts/style-check.mjs path/to/draft.md
```
