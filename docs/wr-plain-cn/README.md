# wr-plain-cn

[← 返回 wr-skills](../../README.md) · [English](../../README.en.md#skills)

> 去机器腔平实中文写作。动笔前核实至少五件具体动作或物件细节，零脑补心理戏，禁用破折号、翻案句、提示性冒号与黑话，交稿前逐条过二十二项指纹自查清单，让文章像一个见过真事的人当面说话。

**支持 Claude Code、Codex、Cursor、Antigravity、claude.ai，以及其他支持 Skills 的 Agent。** 用的 AI 不支持 Skill，也可以直接复制 [提示词清单](提示词清单.md)。

## 解决什么痛点

| 常见 AI 写稿毛病 | 用 wr-plain-cn 之后 |
| --- | --- |
| 满篇破折号、先否定再肯定的翻案句、三连排比和大厂黑话 | 四条硬封底线直接清零，回到主语加动作加数字的自然表达 |
| 没材料就替作者编内心戏（「心里打鼓」「深吸一口气」「恍然大悟」） | 动笔前先清点 5 件核实过的物理细节，未知直写未知，零心理加戏 |
| 通篇大词讲空道理，结尾强行升华到行业未来 | 抽象分类后括号跟具体场景，数字标清样本边界，讲完立刻停笔 |
| 改了一遍感觉还是怪怪的，说不清哪里像机器写的 | 内置 22 项机器腔指纹清单逐条扫描，定位到具体句子直接改平实 |

## 核心写法

1. **5 件物理细节打底**。核实过的动作、物件、空间、声音或带边界数字凑不够 5 件，先补查或写短，绝不编故事凑字。
2. **零脑补心理戏**。只写看得见摸得着的事实，不代人抒情、不代人纠结。
3. **四条硬封底线**。禁破折号、禁先否定再翻过来的句式、禁提示性冒号串长句、禁空洞黑话与公关套话。
4. **22 项机器腔指纹自查**。交稿前按标点句式、词汇黑话、事实心理、结构结尾四大类 22 条逐项排查。
5. **返稿持续贴合语感**。用户改完发回返稿时，自动比对删改差异并记录偏好。

## 配合静态检查脚本

单靠提示词容易偶尔漏网，建议配合本仓库的 [hooks/copy-and-privacy-lint.mjs](../../hooks/copy-and-privacy-lint.mjs) 挂到 `pre-commit` 或发布前命令，把破折号、翻案句、黑话和隐私路径泄漏变成零豁免自动拦截。

## 安装

只装这一个技能，运行下面这行命令。

```bash
npx -y skills add WindriseAI/wr-skills -g --skill wr-plain-cn
```

一键安装全套风起技能，运行下面这行命令。

```bash
npx -y skills add WindriseAI/wr-skills -g --all
```

更多安装方式见 [主说明文档](../../README.md#安装)。
