## 一、起草一篇平实中文长文或经验复盘

```text
请根据下面我提供的真实素材，写一篇【公众号长文 / 经验复盘 / 教程 / 口播稿】，大约【字数范围】。

【粘贴你的原始笔记、实测数据、事件经过】

动笔前守住下面七条规矩。
1. 从我真做过的一件具体小事开头，讲清楚当初想做什么、第一版看着像样、真上手后怎么接连出问题，不扯宏观行业背景，不端架子。
2. 保持连贯口语长句的呼吸感，一句可以一口气顺下 15 到 40 多个字，把因果、转折、现场和举例自然串下来，关键处再用短句收住。自然保留「然后」「后来我才慢慢想明白」「其实」「所以现在」这类口头连接词，严禁三五字一逗的电报碎句，严禁一行一句装深沉。
3. 按做事的真实先后推进，一小节讲透一个坑和一个解决办法，小节标题用大白话，不硬编第一到第四阶段，不在每段末尾贴教训句。
4. 每条做法讲清踩什么坑、为什么会这样、现在具体怎么干。只举人人都碰得到的通用例子，不塞冷门产品版本号、体积字节数或显摆式测试条数，绝不抄任何参考文章的原话和结构。
5. 最值得照抄的核心做法直接挑明推荐并写全细节；外部链接全文同一个只放一回，不用带货推销词。
6. 全文严禁破折号、严禁「不是……而是……」翻案句、严禁说教冒号、严禁 AI 塑料假俚语。同时守住三条句法检查：同一分句内不用顿号连着并列三项以上（表格和刻意列全的检查清单除外）；正文不用分号接句子，改成句号（表格除外）；相邻三句不套同一个句式骨架，发现三连同构打散其中一句。
7. 零脑补心理戏，未知直写未知，不吹没核实过的数字。事情讲完立刻克制收笔，【如需固定落款，在这里写上你的落款；不需要则删掉这句】。
```

## 二、交稿前只做文风与句法体检（先诊断不改写）

```text
先别直接改写正文。请把下面这篇草稿逐行扫描，只输出问题清单，每条写清原句位置、原句摘录、命中哪一条以及一句平实改法。

【粘贴待检查文稿】

重点查下面七类问题。
1. 破折号：正文里出现的任意破折号。
2. 翻案句：先否定半句再翻过来的套路句（如「不是……而是……」「并非……而是……」）。
3. 说教冒号：「核心在于：」「说白了：」「值得注意的是：」这类把普通陈述句切两半的提示冒号。
4. 塑料假俚语与黑话：强装口语的生硬词和大厂宣讲空洞词。
5. 顿号连串：同一分句内用顿号连着并列三项以上（表格和刻意列全的检查清单除外）。
6. 分号拆句：正文里用分号接起来的句子（表格除外）。
7. 相邻句同构：相邻三句套同一个句式骨架（如连续三句「第一道……第二道……第三道……」）。

顺便标出：有没有脑补当事人的心理活动、有没有没标来源和样本边界的数字、有没有三五字一逗的碎句、有没有同一个链接重复贴了多次。
```

## 三、按体检清单做最小改写（不越改越短）

```text
请只针对刚才确认要改的条目做最小改写，其余正常表达原样保留。

改写约束。
1. 改顿号连串时，拆成逗号或拆开来说，不要删掉原有事实。
2. 改正文分号时，直接改成句号或顺成自然长句，不丢原意。
3. 改相邻句同构时，只打散其中一句的句式骨架，不要把三句合并压缩成提纲。
4. 严禁越改越短，改完后总字数保持在原稿的 95% 到 105% 之间，保留原本的口语连贯感。
```

## 四、把用户返稿沉淀成个人写作偏好

```text
下面第一段是我之前的草稿，第二段是我自己改完定稿的版本。请逐句对比两版差异，总结出我删掉了哪些表达、换掉了哪些词、调整了哪些断句节奏，整理成 5 到 8 条可复用的写作偏好，以后动笔直接照着执行。

【初稿】

【我的修改定稿】
```
