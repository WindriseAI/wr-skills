## 一、起草一篇平实活人中文稿

```text
请根据下面我提供的真实素材，写一篇【公众号文章 / 产品更新日志 / 技术复盘 / 口播稿】，大约【字数范围】。

【粘贴你的原始笔记、实测数据、事件经过】

动笔前守住下面五条铁律。
1. 先核对素材里有没有至少 5 件核实过的物理细节（具体动作、物件、界面文字、环境声音或带样本边界的数字）。不够 5 件先列缺口问我，严禁编造「有个朋友」来凑字数。
2. 零脑补心理戏，严禁替我补充没说过的紧张、犹豫、兴奋、顿悟等心理活动。未知细节直说不知道。
3. 硬封四类表达，全文不用破折号；不写先否定半句再翻过来的句式；不用提示性冒号把一句话硬切两半；不用任何商业黑话、公关套话和夸大词。
4. 提到抽象分类时，括号里跟一个具体日常场景；引用数字时说明测试环境或样本边界。
5. 像一个见过真事的朋友当面说话，长短句自然交替，不凑三连排比。事情讲完立刻停笔，不在结尾拔高升华。
```

## 二、用 22 项机器腔指纹体检并只给诊断报告

```text
先别直接帮我改写。请把下面这篇草稿逐句对照「22 项机器腔指纹」做一次体检。

【粘贴待检查文稿】

重点查下面四类问题。
1. 标点与句式，查破折号、先否定再翻过来的句式、提示性冒号串长句、三连对称排比、公文过渡词（综上所述/值得注意的是）。
2. 词汇与语气，查商业黑话、玄学概念词、夸大词（极致/颠覆/重塑）、把简单动词名词化、满篇粗体小标签、主持人口吻。
3. 事实与心理戏，查脑补未证实的心理描写、无边界数字、泛泛的「不少用户」、通篇讲道理缺少 5 件具体物理细节。
4. 结构与结尾，查开头扯宏观背景、客服式先夸后抑、段落等长豆腐块、结尾强行升华喊口号。

按「位置 + 原句摘录 + 命中的指纹项 + 建议怎么改直白」列出清单，让我决定改哪些。
```

## 三、把满篇 AI 味的旧稿洗干净（保留事实，去掉脂肪）

```text
下面这篇草稿事实没问题，但读起来机器味太重，【粘贴草稿】。

请只做去脂肪重写，遵守下面四条边界。
1. 只保留原文已有事实和数字，不新增任何未经核实的例子、数据或心理活动。
2. 清掉全部破折号、先否定再翻过来的句式、提示性冒号长句、商业黑话、对称排比和结尾升华。
3. 把抽象大词全换成具体动作和日常说法，能用十个字说清的绝不用二十个字。
4. 改完后顺手列 3 条删掉废话最明显的前后对照，方便我复核有没有丢掉原意。
```

## 四、给小红书或短视频口播做双稿对照

```text
请基于这份真实素材【粘贴素材】，同时给我两版中文稿。
- 第一版（平实标准稿），严格遵守 5 件物理细节、零心理加戏、零破折号、零翻案句、零黑话、讲完就停，并且把容易触平台限流的外部链接或生硬广告词换成自然场景说法。
- 第二版（自由探索对照稿），不受上述规则约束，从更强开场抓力或更紧凑口播节奏出发自由重写，并在开头用两句话说明调整思路，方便我对比取舍。
```
