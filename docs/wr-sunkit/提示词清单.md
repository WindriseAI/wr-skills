## 一、拍照算热量

思路：饭前拍一张，饭后拍一张，让 AI 估吃了多少；一天结束再汇总。估算有误差，看趋势比看单餐数字更有用。

### 0. 第一次用，先交代你自己（只发一次）

```
接下来一段时间，你是我的饮食记录助手。我的基本情况：
- 性别【男/女】，年龄【30】，身高【175cm】，体重【75kg】
- 目标：【减脂 / 增肌 / 维持】，每天目标摄入大约【1800】千卡（不确定就帮我按以上信息估一个，并说明怎么算的）
- 忌口或特殊情况：【无 / 乳糖不耐 / 控糖 等】

之后我会发饭菜照片。每次都按同一个格式回复，方便我最后汇总。记不住前面的内容时直接告诉我，别编。
```

### 1. 饭前拍照

```
这是我【午饭】饭前的照片。请：
1. 列出你看到的每样食物，估计份量（用碗、手掌、筷子、餐盘这类参照物说明你怎么估的）
2. 每样给热量区间和蛋白质、碳水、脂肪的克数，最后给这一餐合计
3. 标出你最没把握的一项，告诉我补拍什么角度或补充什么信息能估得更准
4. 按我的目标，建议这顿的吃法：先吃什么、哪样可以少吃一半
只要表格加三句以内的建议，不要长篇解释。
```

### 2. 饭后补拍

```
这是同一餐饭后的照片，对比饭前那张，估算我实际吃掉了多少。
只给：实际摄入热量区间、三大营养素、和饭前估算相比少吃了哪些。
```

### 3. 一天结束汇总

```
把今天所有餐的记录汇总成一张 Markdown 表：餐次、主要食物、热量、蛋白质、碳水、脂肪。
然后告诉我：
- 今天总摄入 vs 目标，差多少
- 【可选：今天手环/戒指显示消耗 2300 千卡，睡眠 6.5 小时】据此算热量缺口
- 明天只改一件事，最值得改的是什么
```

### 4. 存档，换个 AI 也能接着用

```
把我到目前为止的基本情况、目标、每日记录和你观察到的饮食规律，整理成一个 Markdown 文档。
要求：另一个 AI 读完这份文档，不需要问我任何问题就能接着帮我记录。
```

> 提醒：拍照估热量误差常在两三成，油和酱料最容易低估。孕期、慢性病、有进食障碍倾向的人，饮食目标请听医生或营养师的。

## 二、三家 AI 出上中下策

思路：同一份现状，分别交给三家不同的 AI，每家都出上、中、下三策；再把三份答案放到一起比，看共识和分歧，最后多半取中策。三家模型训练方式不同，盲点不完全重合，交叉比一比能少踩一个人的坑。

### 1. 先写现状卡（自己填，填完整比提示词更重要）

```
【现状卡】
我要决定的事：【例如：要不要辞职全职做自媒体】
现在的情况：【收入、存款、已经做了多久、目前数据】
我想要的结果：【一年后希望是什么样】
硬约束：【房贷每月 6000，存款只够撑 8 个月，家人反对……】
已经试过的：【下班后做了 6 个月，粉丝 3000】
底线：【什么情况我绝对不能接受】
截止时间：【我需要在什么时候前做决定】
```

### 2. 把下面这段加上现状卡，分别发给三家 AI

```
下面是我的现状卡。请给我上、中、下三策：
- 上策：争取最好结果，风险可以高
- 中策：收益和风险平衡，大多数人能执行
- 下策：最保守，先保住底线

每一策都写清楚：
1. 具体怎么做（写到我明天就能开始的第一步）
2. 成立的前提是什么，前提不成立会怎样
3. 最坏情况和我能不能承受
4. 能不能反悔，反悔的成本
5. 你最推荐哪一策，为什么

信息不够的地方直接问我，不要自己假设。不要安慰我，只要能执行的方案。

【粘贴现状卡】
```

### 3. 汇总裁判（把三份回答一起贴给其中一家，或第四家）

```
我把同一个问题分别问了三个 AI，下面是 A、B、C 三份回答。请你当裁判：
1. 三家都同意的点（这些大概率靠谱）
2. 三家分歧最大的点，各自的理由，你认为谁更对
3. 只有一家提到、但我不能忽略的风险
4. 综合后的中策：取三家中策的共同部分，补上遗漏的风险对策，写成一份 30 天行动清单
5. 什么信号出现时，我应该改走上策或退到下策

A：【粘贴】
B：【粘贴】
C：【粘贴】
```

> 提醒：现状卡里别放身份证号、账户、病历原件这类敏感信息，用数字区间代替就够了。

## 三、让 AI 当你的反对者

思路：AI 天生爱顺着你说。要它有用，就得明确给它"反对你"的任务，并且堵住它退回附和的路。

### 1. 反对者模式（核心）

```
从现在起你是我的反对者。你的任务是找出我这个想法会失败的理由，不是帮我完善它。

规则：
- 不要说"这个想法很好，但是……"，直接说问题
- 给出最有力的 5 条反对理由，按"会不会让整件事失败"排序
- 每条写明：什么证据能证明你这条反对是错的
- 最后问我 3 个你认为我答不上来的问题
- 我反驳之后，只有我真的解决了问题你才能让步；我只是情绪上坚持，你就继续反对

我的想法：【粘贴你的计划、决定或观点】
```

### 2. 事前验尸

```
假设现在是一年后，我这个计划彻底失败了。请写一份失败复盘：
- 最可能的 3 条失败路径，每条从第一个信号写到最后的结果
- 每条路径里，我现在就能看到的早期信号
- 现在花最少的成本，能先堵住哪一条

我的计划：【粘贴】
```

### 3. 反附和开关（加在任何对话的末尾）

```
如果你同意我，只是因为我是这么说的，请直接指出来。我宁可听到不舒服的真话。
```

### 4. 换个立场再打一轮

```
现在换成【我的老板 / 投资人 / 最挑剔的用户 / 我的竞争对手】的身份，用他最在意的东西来反驳我。
只说他会说的话，不要替我圆场。
```

## 四、三件套怎么串起来

- 每天：拍照记饮食，睡前汇总一次，每周存一次 Markdown 档
- 遇到大决定：先写现状卡 → 三家各出上中下策 → 裁判汇总 → 拿汇总出来的中策去找"反对者"打一轮 → 打不倒再执行
- 所有记录都存成 Markdown 文档，换哪家 AI 都能直接接手
