# wr-10x-goal

[← 返回 wr-skills](../../README.md) · [English](../../README.en.md#skills)

> 定十倍目标并堵死作弊与假通过。在动手前把上下文和边界交代清楚，要求方案在速度、现成方案对比和体积瘦身上追求十倍差距，同时硬性禁止靠删功能、假返回值、跳过慢路径和改弱断言来凑指标。

**支持 Claude Code、Codex、Cursor、Antigravity、claude.ai，以及其他支持 Skills 的 Agent。** 用的 AI 不支持 Skill，也可以直接复制 [提示词清单](提示词清单.md)。

## 为什么既要十倍目标又要防作弊

只跟 AI 要百分之十的改进，它通常只在旧结构里小修小补；直接把目标抬到十倍，才能逼出并行拆分、批量接口、删除冗余依赖这些真正换结构的做法。但硬压高指标时，AI 很容易走邪路，偷偷删掉难测的分支、写死假返回值或者把断言改松来骗过检查。这个技能把两件事焊死在同一套流程里。

| 常见翻车现场 | 用 wr-10x-goal 之后 |
| --- | --- |
| 问 AI 怎么提速，只改了几行循环细节，整体还是卡顿 | 先交代清楚上下文和物理下限，从并行结构、批量化、零拷贝上按十倍提速重设计 |
| 不查现成生态直接手写，花了两天造出带一堆坑的半成品 | 动手前搜齐 10 个仍在维护的现成开源方案对比体积、许可证与维护近况 |
| 每次重构不敢删旧代码，只敢套新壳，仓库越来越重 | 一次迁完所有调用方并删光死代码与废依赖，交卷报净增减行数和字节数 |
| 为交差删功能、写死返回成功、跳过慢路径或把测试改松 | 强制核验防作弊四条红线，必须拿同一套真路径测试和突变检查交卷 |

## 三个十倍动作

1. **追求 10 倍速度（用 0.1 倍时间完成）**。先算清楚磁盘、内存和网络的物理下限，把串行等待拆成多路并发、批量合并或流水线，目标是用十分之一的时间把同类活跑完。
2. **动手前搜齐 10 个现成方案**。联网对比最多 10 个仍在维护的开源方案或成熟做法（搜不到 10 个如实报数，不许编链接），看清许可证、依赖体量和踩坑点后再决定直接用还是借鉴边界测试写精简版。
3. **体积与冗余压小 10 倍**。清理死代码、冗余开关、无用包装层和重型依赖，内部重构全仓一次迁完删旧接口，汇报真实体积与行数净减。

## 四条防作弊红线

1. **严禁偷删功能或缩水验收范围**，权限校验、加密验签、错误兜底和边界处理一条不能少。
2. **严禁硬编码假返回值或伪造成功状态**，不许绕开真实的读写和计算直接返回成功。
3. **严禁跳过慢路径或全换假替身**，真实解析、编译、渲染和端到端流程必须全量跑通。
4. **严禁改弱测试断言或跳过用例**，不许把严格相等改成模糊匹配，也不许靠筛选跑出 0 条用例报绿。

## 安装

只装这一个技能，运行下面这行命令。

```bash
npx -y skills add WindriseAI/wr-skills -g --skill wr-10x-goal
```

一键安装全套风起技能，运行下面这行命令。

```bash
npx -y skills add WindriseAI/wr-skills -g --all
```

更多安装方式见 [主说明文档](../../README.md#安装)。
