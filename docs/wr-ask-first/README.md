# wr-ask-first

[← 返回 wr-skills](../../README.md) · [English](../../README.en.md#skills)

> 先质疑挑坑，再问透立据。动手前搜齐 10 个现成开源方案，先挑出需求里的泄密、上下文爆炸、自相矛盾与二三阶隐患，再用决策树分轮追问落盘 `docs/SPEC.md`。

**支持 Claude Code、Codex、Cursor、Antigravity、claude.ai，以及其他支持 Skills 的 Agent。** 用的 AI 不支持 Skill，也可以直接复制 [提示词清单](提示词清单.md)。

## 解决什么痛点

| 常见翻车现场 | 装上 wr-ask-first 之后 |
| --- | --- |
| 发了一句模糊想法，AI 夸完「好主意」就开始闷头写几千行错代码 | 禁止附和开场，先当面指出泄密、上下文爆炸、自相矛盾和后续隐患 |
| AI 凭记忆手写几百行解析器，编码和边界全漏掉，或者随手装进几十兆重依赖 | 动手前先搜齐 10 个现成开源方案，对比许可证、体积与维护活跃度再拍板 |
| AI 一次性甩二十个问题让人头大，或者啥也不问全靠自己脑补 | 按决策树分轮追问，每轮只问眼前能定的 2 到 4 题，每题附带推荐答案 |
| 讨论卡在方案 A 和方案 B 来回扯皮 | 掀开共同隐藏前提，拿出绕开前提的方案 C 和改写问题的方案 D，附翻车预演 |
| 对话聊到后面，前面定好的规矩全忘了 | 全部决定落盘到仓库唯一的准数文件 `docs/SPEC.md`，后续开发与验收全照它核对 |

## 四步执行流程

1. **搜齐 10 个开源方案与本机技能**。先盘点本机已装的对口 Skill（按需挂载，不拖慢上下文），再横向对比现成开源项目的许可证、体积、依赖、维护近况与已知坑。能用现成就不重造，太重就借测试用例写精简版。
2. **当面质疑挑坑**。把需求放在台面上拆解，逐条检查泄密与权限越界、上下文爆炸、需求自相矛盾、二阶连带破坏与三阶维护账。
3. **决策树逐轮追问与破局**。仓库里能查到的事实自己去查不问人；按依赖分轮发问并给出推荐选项；陷入二选一时拆穿隐藏前提、推演上线半年后怎么翻车，高代价决策支持多模型盲审。
4. **落盘 `docs/SPEC.md` 立据**。写清目标与不做的事、互斥数据结构、边界失败处理、连带影响和量化验收标准，经用户确认后才允许动代码。

## 安装

只装这一个技能，运行下面这行命令。

```bash
npx -y skills add WindriseAI/wr-skills -g --skill wr-ask-first
```

一键安装全套风起技能，运行下面这行命令。

```bash
npx -y skills add WindriseAI/wr-skills -g --all
```

更多安装方式（Claude Code 插件市场、直接让 Agent 安装、手动复制）见 [主说明文档](../../README.md#安装)。
