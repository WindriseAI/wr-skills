# wr-ux-craft

[← 返回 wr-skills](../../README.md) · [English](../../README.en.md#skills)

> 界面省心规矩与跟手动效设计。按只点默认按钮的新手视角过八条省心规矩和十二种状态变化对应的七条跟手动效标准，加上斜向移鼠防劫持走廊与点击锁定、任意条数据弹性扩容，以及改一处往后多想两步的连带推演。

**支持 Claude Code、Codex、Cursor、Antigravity、claude.ai，以及其他支持 Skills 的 Agent。** 用的 AI 不支持 Skill，也可以直接复制 [提示词清单](提示词清单.md)。

## 解决什么痛点

| 常见界面毛病 | 用 wr-ux-craft 之后 |
| --- | --- |
| 界面堆满要人手填的配置，报错直接甩英文代码，满屏紫蓝渐变和套娃卡片 | 先锁样式变量底表，按只点默认按钮的新手视角过 8 条省心规矩，复杂事收进代码 |
| 动画各动各的，点击慢吞吞锁死操作，或者逐帧改宽度把手机拖掉帧 | 按 12 种状态变化核查 7 条跟手标准，保证一套曲线、随时可打断、只动位移缩放透明度 |
| 悬停展开二级菜单，鼠标斜着一移就误触隔壁把菜单关掉，想复制内容怎么都点不稳 | 建立斜向移鼠三角安全走廊防劫持，同时支持点击锁定浮层与 `Esc` 释放 |
| 样板页只适配 4 个标签或 20 条数据，一加新内容就撑爆边框、竖劈半个字 | 彻底消灭写死数量的像素与下标，数据从 0 条到 100+ 条弹性扩容零截断 |
| 为让画面好看顺手把老用户高频入口删了，或者改一处崩三页 | 每处改动落盘前强制写出二阶连带影响与三阶长期维护账 |

## 五大实战支柱

1. **8 条省心规矩**。程序能判断的别问、低频项先收起、能代劳的直接做完、叫法位置一致、点击即回应且可撤回、不弹窗打断、高频一步到位高危加确认、控件不看说明就懂。
2. **按状态变化查 7 条跟手动效**。覆盖出现、消失、移动、变大小、换内容、换图标、数值跳动、按下、悬停、加载、完成、出错 12 种变化，保证来去清楚、半路能打断、零重排、兼容减动效与深浅色。
3. **斜向移鼠防劫持与点击锁定**。悬停菜单和悬浮详情卡带方向安全走廊，斜向移鼠不误切；支持点击固定面板，阅读操作不手抖。
4. **任意条数据弹性扩容**。内容数据与版式彻底解耦，容器按数据条数自适应等分、折行、紧凑档位或滚动，避免 `em` 自引用缩水切边与固定数量硬编码。
5. **往后多想两步**。每次调整先查二阶（连带页面与老用户习惯）和三阶（三个月后新增数据与排查成本）影响。

## 安装

只装这一个技能，运行下面这行命令。

```bash
npx -y skills add WindriseAI/wr-skills -g --skill wr-ux-craft
```

一键安装全套风起技能，运行下面这行命令。

```bash
npx -y skills add WindriseAI/wr-skills -g --all
```

更多安装方式见 [主说明文档](../../README.md#安装)。
