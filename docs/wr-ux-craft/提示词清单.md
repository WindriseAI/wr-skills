界面省心规矩与跟手动效设计

在界面开工前、功能跑通后或交互精修时，按场景复制对应灰框给 AI，将【方括号】替换为你的页面或组件。

## 一、开工前锁死样式底表，去掉廉价模板味

```text
动手写【目标页面或产品界面】之前，先把颜色、字号、间距、圆角、边框和动效时长写进一份根级样式变量文件，所有页面只引用这份底表。
同时守住下面四条底线。
1. 不用紫蓝渐变和廉价发光玻璃，不拿表情符号当功能图标。
2. 卡片里面不再套卡片，不编造用户数、评分和好评。
3. 桌面 1280x800 首屏不滚动就能看全标题、一句话说明和唯一主按钮；超宽屏锁住最大版心宽度；数字列用等宽字体。
4. 先列出这份样式变量底表给我确认，再写页面代码。
```

## 二、按 8 条省心规矩走查，每处往后多想两步

```text
用一个不看说明、只点默认按钮的新手身份，把【目标界面或流程】从头走一遍，然后直接改代码。按下面这 8 条逐条过一遍。
1. 系统能自己判断的，别再问用户（自动选好并在明处标出当前值，留手动改入口）。
2. 这一步用不上的低频高级选项先收起来，主按钮和安全提示不藏进二级菜单。
3. 能替用户做完的直接做完，报错全用看得懂的中文说明。
4. 同一件事在各个页面叫法和位置保持一致。
5. 每次点击立刻有回应，做错了能一步撤回。
6. 不弹阻塞弹窗打断手上的事。
7. 常用操作一步直达，会丢数据的操作多一步确认。
8. 不看说明也能读懂每个控件。

每改一处之前，先写一句二阶影响（会连带影响哪个页面或老用户习惯）和三阶影响（三个月后新增数据或排错会不会更难），确认没埋新坑再落盘。
```

## 三、按 12 种状态变化打磨 7 条跟手动效

```text
别按组件清单加动画。先把【目标界面】里所有状态变化列齐，覆盖出现、消失、移动、变大小、换内容、换图标、数值跳动、按下、悬停、加载、完成、出错这 12 种变化。
逐条按下面这 7 条标准改代码。
1. 讲清从哪来、到哪去，面板从哪个按钮弹出，关闭就缩回哪个按钮；从 0.96 缩放加透明度进场，不凭空蹦出。
2. 全站一套缓动曲线和两三档时长。
3. 快、轻、不抢戏，每天点上百次的高频操作不加慢动画。
4. 跟手，播到一半再次操作必须从当前位置平滑折返，不锁点击，不跳回起点重演。
5. 只动位移、缩放和透明度，禁止用 width / height / top / left 逐帧动画触发重排。
6. 系统开了 prefers-reduced-motion 时降级成轻淡入淡出或颜色切换，保留状态提示。
7. 宽屏、手机窄屏、浅色、深色四种环境各验一遍。
```

## 四、给悬停菜单和浮层加上斜向防劫持走廊与点击锁定

```text
按下面三条改造【目标悬停菜单、侧栏导航或预览浮层】的交互手感。
1. 实现斜向移鼠安全走廊。记录指针移动轨迹，在当前鼠标点与已展开浮层的两个近角之间构造虚拟三角区域；只要鼠标斜着朝浮层方向移动且位于走廊内，宽限时间内不触发相邻菜单项切换，防止内容被半路劫持关掉。
2. 支持点击锁定。点击触发项或浮层内部时锁定当前浮层，鼠标移出不关闭，方便阅读和复制；再次点击触发项、按 Esc 或点击外部空白处解锁关闭。
3. 键盘焦点切换与触屏设备下同样可用，不依赖悬停才能访问核心操作。
```

## 五、检查任意条数据弹性扩容，消灭写死数量

```text
全面排查【目标页面或组件】里把当前样例数量写死的地方（比如 CSS 固定像素步长、repeat 固定列数、截取固定位数的正则、硬编码数组下标、在缩小字号的同一元素上用 em 定高）。
按下面三条改造成数据驱动的弹性扩容方案。
1. 条目数量从 0 条、1 条、5 条增长到 50 条或 100 条时，布局通过 CSS 变量等分、自动紧凑档位、折行或折叠滚动平滑承接，不撑破外框、不截断文字、不把正文挤成窄缝。
2. 以后增删条目只需修改纯数据文件，不动样式和渲染脚本。
3. 分别用极少数据、正常数据和 3 倍超量数据验一遍宽窄屏效果并汇报结果。
```
