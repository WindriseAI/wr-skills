# wr-split-work

[← 返回 wr-skills](../../README.md) · [English](../../README.en.md#skills)

> 多工作区无重叠并行派活。总协调人只拆活审回执不写代码，一活一棵独立 `git worktree` 切死独占文件白名单，先砍废包瘦身再按模型特点和思考强度多路并行，附通用 Git 与 Orca 双路实操。

**支持 Claude Code、Codex、Cursor、Antigravity、Orca，以及其他支持 Skills 的 Agent。** 用的 AI 不支持 Skill，也可以直接复制 [提示词清单](提示词清单.md)。

## 为什么需要多工作区并行

| 常见翻车现场 | 用 wr-split-work 之后 |
| --- | --- |
| 一个对话聊了几十轮，AI 越写越忘前面的规矩，速度也越来越慢 | 协调人只派活收活，每条子线在全新独立会话里开工，始终保持清醒 |
| 开三个窗口同时改代码，结果互相覆盖，合并冲突解到崩溃 | 一活一棵独立 `git worktree` + 独占文件白名单，两路碰同一文件直接重拆 |
| 改个文案和做底层架构全用最贵模型，额度半天烧光 | 按当前订阅方案结合模型特点和思考强度拆开派活，花钱花在刀刃上 |
| 每次加功能只敢套新壳，安装包和代码越滚越大 | 先做减法删死代码与废包，再按数据版式分离多路并行提速 |

## 实战模型排兵布阵与工作台

1. **总协调人**。用你手上最强的推理档模型（`tier1_architect`）。收到问题先向人汇报方案与做法，再派对应帮手去做。建议挂前置钩子防止协调人闷头看代码不回复：本仓库带了「先应声再动手」（`hooks/speak-before-act-hook.mjs`）；「限制单轮工具调用次数或时长」「拦截协调人直接改业务代码」这两类钩子没有随包提供，需要时按 `wr-hook-forge` 自己写。
2. **总设计师**。界面与设计类的活固定交给同一档模型（通常也是最强推理档），不在中途换模型。
3. **其余执行、排错与分析任务**。按手头现有订阅方案，由总协调人结合模型特点和不同思考强度拆开派给各自最拿手的档位；只有一个模型时就是单模型模式，不分档。
4. **工作台可选**。多代理工作台（例如开源的 Orca）能省去手动开窗口和转述的功夫，没有也能用纯 `git worktree` 路线完成全部流程。

## 核心机制

1. **角色切死**。总协调人只负责拆任务、查前置事实、审三句话回执与最终合并，绝不亲自写业务代码。
2. **物理隔离**。通过 `git worktree` 让每条子线有独立目录与独立分支，文件白名单硬约束零重叠。
3. **按需路由模型**。按 `tier1_architect`（架构与审美）、`tier2_builder`（逻辑攻坚）、`tier3_reviewer`（独立核查）、`tier4_runner`（机械跑腿）四档映射到当前订阅下的各家模型。
4. **先减法后并发**。先砍冗余依赖与死代码把体积压薄，再把数据层、样式层、逻辑层、测试层拆成多路并行推进。
5. **双路实操**。同时覆盖纯命令行 `git worktree` 通用方案，以及 Orca 多代理工作台调度方案。

## 配置示例

第一次启用技能时会先做首次对齐，把答案写进项目根目录的 `wr.config.json`（完整模板见 [examples/wr.config.example.json](../../examples/wr.config.example.json)，字段说明见 [examples/README.md](../../examples/README.md)）。四档模型按你手头的账号填写，全部留空就是单模型模式。

```json
{
  "modelTiers": {
    "tier1_architect": "最强推理档，例如你订阅里最贵的那个模型",
    "tier2_builder": "主力编码档",
    "tier3_reviewer": "独立复核档，有第二家厂商就填那家的",
    "tier4_runner": "快速经济档"
  }
}
```

## 安装

只装这一个技能，运行下面这行命令。

```bash
npx -y skills add WindriseAI/wr-skills -g --skill wr-split-work
```

一键安装全套风起技能，运行下面这行命令。

```bash
npx -y skills add WindriseAI/wr-skills -g --all
```

更多安装方式见 [主说明文档](../../README.md#安装)。
