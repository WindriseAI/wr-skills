# 官网 GEO/SEO 提示词清单

让搜索引擎和 AI 助手读得到、说得对你的网站

> 出处：Windrise AI · [github.com/Hestamen/wr-skills](https://github.com/Hestamen/wr-skills) · 采用 CC BY-NC 4.0 授权，转载请注明出处，禁止用于付费课程等商业用途。

用法：按顺序用，前面的做完再做后面的。把灰框整段复制过去，把【方括号】换成你自己的，把 `example.com` 换成你的域名。**不要跳步**：没做第一步的实测，后面全是在猜。

哪家 AI 都行，但要守一条：它说数字（搜索量、排名、流量）时，你要问「哪来的」。给不出来就是编的。

## 一、线上体检（只读，不改任何东西）

思路：先让 AI 把「能核实的」核一遍，逐条给证据。这一步只该产出表，不该产出改动。

### 1. 爬虫能不能进来

```
我在核查我的网站对搜索类爬虫和 AI 搜索的可达性。域名：https://example.com

请给我一组可以直接复制执行的 curl 命令（只读），对下面每个爬虫标识，分别请求首页和【/pricing、/help】这几个页面，输出状态码：
OAI-SearchBot、Claude-SearchBot、PerplexityBot、bingbot、Googlebot、【Baiduspider（面向中文用户时加）】

命令写成一行一条，形如：
curl -s -o /dev/null -w "%{http_code}" -A "爬虫标识" 网址

然后告诉我：什么状态码算通过，哪些状态码分别意味着什么（403 / 429 / 503 / 超时），以及如果被拦了该去哪里查（CDN、WAF、robots、服务端 UA 过滤）。
不要替我下结论说「应该没问题」，必须等我贴回实际输出。
```

### 2. 读线上的 robots.txt

```
请给出一条命令，抓取 https://example.com/robots.txt 的完整内容（不要用仓库里的那份，CDN 可能在文件头部自己加规则）。

拿到内容后，按这几条判断，每条给「通过 / 不通过」和对应的那一行：
1. 有没有 User-agent: *
2. 有没有 Sitemap: 指到绝对地址
3. 有没有 Disallow: / 这类拦整站的规则
4. 有没有点名拦 OAI-SearchBot、Claude-SearchBot、PerplexityBot、bingbot、Googlebot、Baiduspider
5. 有没有对训练类爬虫（GPTBot、ClaudeBot、Google-Extended）的规则，如果有，说明那只影响训练、不影响搜索结果里的引用

不确定的写法直接说「不确定」，不要猜搜索引擎会怎么解释。
```

### 3. 不跑 JS 时页面里有什么

```
我有一个脚本能同时抓「原始 HTML 的可见文字」和「浏览器跑完 JS 后的可见文字」。命令是：

node render.mjs out home=https://example.com/@1440x900

我会把 out/home.raw.txt（原始 HTML）和 out/home.txt（渲染后）贴给你。请对比这两份，回答：

1. 原始 HTML 里有没有页面标题和正文主体？有，占渲染后的百分之多少？
2. 有哪些整句只在渲染后才出现？逐条列出。这些内容对不跑 JS 的爬虫等于不存在。
3. 原始 HTML 的语言和渲染后是否一致？价格数字是否一致？
4. 我该优先把哪几块内容做成静态的？按「不做就会丢内容」排序。

只根据我给的文件回答，不要推测我没贴的部分。
```

### 4. 重复地址与跳转

```
域名：https://example.com
请给我一组 curl 命令（-I 只看头），检查下面这些地址各自返回什么，并把 301 的 Location 也打出来：
http://example.com/、http://www.example.com/、https://example.com/、https://www.example.com/、
https://www.example.com/index.html、https://www.example.com/pricing、https://www.example.com/pricing.html、https://www.example.com/pricing/

判断标准：每个页面只能有一个地址返回 200，其余全部 301 到那个地址。请按这个标准逐条给通过 / 不通过。
```

## 二、写契约

思路：把「要改成什么样」写成一份逐字固定的文件。写完之后实现和验收都照它，谁都不许临时改口径。

```
下面是我们的真实情况。请帮我写一份 SEO / GEO 契约，写成 Markdown 文件，要求：标识符逐字固定，文案只给底稿。

【固定事实】
- 产品名：【英文名】（中文名【中文名】）
- 站点根：【https://example.com】；第二语言站根：【https://example.org】
- 支持邮箱：【hello@example.com】
- 支持平台：【Windows 10 / 11；Mac、安卓未定】
- 现在能不能下载：【不能，页面上不许出现下载地址和版本号】
- 价格：【没定价就写「未定，页面不出现价格」】
- 页面上不许出现的过期说法：【逐条】

【可收录页】
【/、/pricing、/privacy、/terms……；哪些页配 hreflang，哪些不配】

契约必须包含这些小节：
1. 固定事实（上面这些，逐字）
2. 可收录页与规范地址表，含 hreflang 对应关系；说明哪些页不进 sitemap、哪些页带 noindex
3. 每个可收录页的 <head> 必须有：title、description（给长度区间）、canonical、og:*、twitter:card、结构化数据
4. 结构化数据的节点和字段；明确禁止 aggregateRating、review、FAQPage、HowTo、downloadUrl
5. 标题与描述底稿表（按页一行）
6. 站点级文件：robots.txt、sitemap.xml、llms.txt 各自的要求
7. 原始 HTML 要求（不跑 JS 就要成立）
8. 不许做的事

做不到的地方写「待定」，不要编数字。价格和日期没定就写「未定」。
```

## 三、改（一次只改一类）

```
你是实现的人。下面是我们定好的契约（粘贴契约全文）和这次要改的范围：【只改 <head> 标签，不动版式】。

规则：
1. 每次只做一类改动，列成清单：改哪个文件、怎么改、用什么命令或什么页面能验证。
2. 不许改页面版式、样式、动画，不许删页面。
3. 碰 robots.txt、canonical、跳转、noindex 之前，先把准备改的差异贴给我，我说可以才动手。
4. 不许为了让它「看起来通过」而加关键词、隐藏文字、假评价、星级评分。
5. 做完把「改了哪些文件」和「自检结果」分开写：自检只算自检，不算验收。

先给我第一批要改的清单，等我确认再改。
```

## 四、独立验收（换一家 AI，不要给实现的人看判据）

思路：实现和验收必须是两份。这一步的提示词交给**另一家** AI，或者交给同一个 AI 的新对话，并且不给它实现过程的上下文。

```
你是验收的人，不是实现的人。你的任务是找出这个站还没做到的地方，不是帮它修改。

这是我们定好的契约（粘贴契约全文）。这是构建产物目录里可收录页的清单（粘贴）。这是检查脚本的输出（粘贴全文）。

请：
1. 逐条核对契约和脚本输出：契约里的每一条，在脚本输出里是不是都有一条对应的 PASS？有没有哪条契约根本没被检查？把「契约有、脚本没查」的列出来。
2. 有没有哪条 FAIL 被解释成「不重要」就放过了？逐条说它会不会真的影响被收录或被引用。
3. 有没有 PASS 但证据可疑的？比如 canonical 存在但地址是错的、description 够长但只是堆词。
4. 只报告，不要修改文件。

结论按「必须修 / 建议修 / 可以不管」三档，每条附证据（脚本输出的那一行）。
```

## 五、内容（基础打完再做）

### 1. 真实买家会问的问题

```
我的产品是【一句话说明】，目标用户是【谁】。

请起草 20 个这个产品真实买家会在搜索引擎或 AI 里问的问题。
要求：
- 按「搜了之后会决定买不买」排序，最接近掏钱的排前面
- 每个问题标注它是「用户真的会这么问」还是「猜的」
- 猜的那些，告诉我该去问谁、去哪看（客服记录、论坛、搜索建议）才能换成真的

不要编搜索量。给不出就用「没核」。
```

### 2. 决策页选题

```
我想做 5 个「决策页」：X 对比 Y、X 的替代品、某类人最适合的 X、X 的价格、X 值不值得买。

对每个选题，先告诉我：
1. 现在搜这个词，排在前十的是什么类型的页面（官方文档、评测站、论坛帖、视频）
2. 我们这页要能站住，必须多出来哪一样东西（实测数据、真实限制、对比表、定价细节）
3. 需要的素材我们有没有：没有的列出来

在我选定之前，一页都不要写。
```

### 3. 带日期的事实单

```
把下面这些事实写成一份 Markdown 事实单，供我和各家 AI 核对口径用：
【产品名、一句话它是什么、支持平台、价格档位、可收录页地址、不支持的平台、常见误解】

要求：
- 第一行 # 【产品名】
- 第二行一句话说清它是什么
- 写在今天日期下，标成 Checked on: 【YYYY-MM-DD】
- 价格逐档列出，和价格页逐字一致；不展示价格的站只写免费额度
- 不写下载地址，不写「已发布」，不写没定的平台许可

以后哪家 AI 说错了，我就按它引用的网页去改源头。
```
