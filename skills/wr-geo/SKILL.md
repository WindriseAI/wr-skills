# wr-geo：让搜索引擎和 AI 读得到、说得对你的网站

大部分 SEO / GEO 建议其实是同一打老办法。这个 Skill 只做能核实的那部分，并且按「先查、再定、后改、另验」的顺序做，避免把站改坏。

## 四条铁律

1. **数字只来自工具或你抓到的页面，不来自记忆。** 核不了就写「没核」。永远不编搜索量。
2. **先查不改。** 第一步只读线上，逐条给「通过 / 不通过」和证据（那一行、那个状态码）。
3. **碰 robots.txt、canonical、跳转、noindex 的改动，先给人看差异，点头再发。永远不删页面。**
4. **不加评分星级、不加 FAQ 标记、不加 HowTo 标记**（没有真实评价就不该有星；后两种搜索引擎早已基本不展示）。

## 第一步：实测线上（只读）

对首页和每个主要页面：

- **爬虫进得来吗**：用各家标识请求，状态码必须是 200。
  `curl -s -o /dev/null -w "%{http_code}" -A "OAI-SearchBot/1.0" https://你的站/`
  至少测：`OAI-SearchBot`、`Claude-SearchBot`、`PerplexityBot`、`bingbot`、`Googlebot`，面向中文用户再加 `Baiduspider`。实时回答靠的是这些「搜索类」爬虫；`GPTBot`、`ClaudeBot`、`Google-Extended` 是训练用的，拦不拦是另一回事，别混为一谈。
- **读线上的 robots.txt，不是仓库里那份。** CDN 可能在文件头部自己加一段规则。
- **不跑 JS 时有没有真内容**：`node scripts/render.mjs` 会同时抓「原始 HTML 的可见文字」和「浏览器跑完 JS 后的可见文字」并对比。原始 HTML 里没有标题和正文，等于给不跑 JS 的爬虫一张白纸；原始 HTML 是另一种语言或另一套价格，比白纸更糟。**每个可收录页都要测，不要只测首页。**
- **重复地址**：`http://` 是否跳 `https://`、裸域名是否跳 `www`（或反过来）、`/page` 与 `/page.html` 与 `/page/` 是否只有一个返回 200。
- **基础标签**：title、description、canonical、Open Graph、sitemap、结构化数据有没有。

产出：一张「检查项 × 通过/不通过 × 证据」的表。到此为止什么都不改。

## 第二步：写契约

把要落地的东西写成一份文件（模板见 `references/contract-template.md`），**标识符逐字固定**：域名、每个可收录页的规范地址、产品名、价格、邮箱、多语言互指关系。文案（title / description）给底稿，只有与页面真实内容不符时才允许改，改了要列「原文 → 改后 → 为什么」。

契约里同时写清**不许做的事**：不许改版式、不许删页面、不许出现哪些过期说法。

## 第三步：修

从最小的改起。每条改动写明：改哪个文件、怎么改、用什么命令验证。多语言站点的静态产物必须就是目标语言，不能靠浏览器里再翻译；内容只能有一个来源，不许静态一份、脚本里再抄一份。

## 第四步：另一份检查来验收

实现的人自己写的自检只算自检。验收用 `scripts/seo-check.mjs` 加一份**实现者没参与写的**配置去跑构建产物；实现者是 AI 的话，这份配置和判据不要给它看。通过项都要对应到当前提交。

## 第五步：只有人能做的事

列给站长，按顺序：Google Search Console、Bing Webmaster Tools（开 IndexNow）、面向中文用户加百度搜索资源平台；软件目录和发布平台（名字、一句话介绍、logo 全部一致）；注册时加一问「从哪知道我们的」。

## 第六步：内容（可选，等基础打完）

- 起草 20 个真实买家会问的问题，**猜的要标出来**，让站长换成真的。每个问题在各家 AI 上至少问两次、不登录，记下谁被点名、引用了哪些网址。
- 提 5 个「决策页」（X 对比 Y、X 的替代品、某类人最适合的 X、X 的价格）。每个先搜一遍，写清现在前十名是什么类型的页面、我们这页多出来的一样东西是什么。**站长选定之前一页都不写。**
- 写一份带日期的事实单（价格、套餐、平台），以后各家 AI 说错了，就顺着它引用的网页去改源头。

## 脚本

- `scripts/seo-check.mjs <配置.json> <产物目录>`：按配置逐页检查 title、description、canonical、Open Graph、hreflang 对称、结构化数据（含禁用项）、robots、sitemap、禁用说法。配置格式见 `references/config-example.json`。退出码非 0 表示有不通过。
- `scripts/render.mjs <输出目录> <名字>=<网址>@<宽>x<高> …`：用本机的 Edge 或 Chrome 无头渲染，输出截图、渲染后的可见文字和横向溢出像素。不需要安装任何依赖。
